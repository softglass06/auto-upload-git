# Git 新手助手

一个 Windows 傻瓜式 Git 工具:双击图标打开一个**中文菜单**,上传项目、更新、查看改动、拉取更新都在里面点选完成,不需要记任何 git 命令。

## 功能

双击 `upload.cmd` 打开中文菜单:

- **[1] 上传新项目** — 第一次把一个项目传到 GitHub。自动识别三种情况:
  - 文件夹自带 `.git` → 原地提交并推送
  - 没有 `.git` → 选择「新建独立仓库」或「复制进某个已有仓库」
- **[2] 更新项目** — 项目有改动,一键推上去(自动过滤测试/构建文件)
- **[3] 查看改动** — 看看哪些文件变了、最近提交了什么
- **[4] 拉取更新** — 把远程的最新改动下载下来

拖拽也可以:把文件夹直接拖到 `upload.cmd` 图标上,自动进入「上传」流程。

### 其它贴心点

- **双重过滤**:`filter-rules.txt` 的默认规则 + 项目自己的 `.gitignore`(原地提交靠 git 识别;复制模式也会读源文件夹的 `.gitignore`,暂不支持 `!` 取反)
- **只过滤新增文件**:过滤规则只作用于「还没被 git 追踪的新文件」;已经追踪的文件改动/删除一律照常提交
- **中文描述 → 规范提交**:打一句中文,用 Claude 润色成简洁的提交信息(没装 Claude 就退回原文)
- **引导建仓**:仓库没关联远程时,给出中文分步提示,去 GitHub 建好空仓库后把地址粘回来即可
- **基础 .gitignore**:新建仓库时自动生成,忽略 `node_modules` 等常见文件
- **先预览后提交**:提交前先列出会传哪些、跳过哪些,确认才动手

## 安装

1. 下载 / 克隆本仓库到本地,例如 `D:\auto-upload-git`
2. 把 `upload.cmd` 发送快捷方式到桌面(可以右键重命名为「Git 助手」)
3. 双击桌面图标即可使用

## 依赖

- **Windows**(PowerShell 5.1 或更高)
- **git**,且在 PATH 中(没装会弹出中文安装引导)
- **Claude Code CLI**(可选,用于润色提交信息;没装会退回用你输入的原文)

## 配置

### repos.txt(我的项目列表)

每行一个,格式 `名字|完整路径`,`#` 开头是注释:

```
我的网站|D:\code\my-website
小白爬虫|D:\codework\green-hand-bug
```

上传新项目后,按提示可以自动加进这个列表,之后「更新 / 查看 / 拉取」就能直接选它。

### filter-rules.txt(过滤规则)

- `#` 开头是注释
- 目录名后加 `/` 表示整个目录跳过,例如 `node_modules/`
- 带 `*` 或 `?` 的通配符匹配文件名 / 目录名,例如 `*.test.*`
- 不带斜杠的普通名字匹配任何一层的同名目录或文件,例如 `__pycache__`

## 常见问题

- **为什么之前脚本全英文?** 老版本为了避开 PowerShell 5.1 的 GBK 编码坑,刻意只用 ASCII。现在 `upload.ps1` 已存为 **UTF-8 带 BOM**,中文能正确显示。**注意:请不要用编辑器把它另存为无 BOM 的编码**,否则中文会乱码或吞行。
- **想跳过 Claude 润色?** 不装 Claude Code CLI 即可,脚本会自动退回用你输入的原文。
- **推送失败提示「远程仓库不是空的」?** 说明建仓库时勾了 README 等选项。去 GitHub 删掉该仓库,重新建一个空的(三个复选框都不勾)再试。
- **别把含个人路径的 `repos.txt` 提交上去。**
